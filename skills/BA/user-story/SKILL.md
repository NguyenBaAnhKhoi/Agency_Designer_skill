# User Story & Acceptance Criteria for Designers

## Overview
Translates broad creative briefs into structured User Stories and verifiable Acceptance Criteria (AC).

## Standard Format
```markdown
### US-[ID]: [Title]
**As a** [Target User / Persona / Client]  
**I want** [Specific visual element / layout / asset]  
**So that** [Business or aesthetic outcome achieved]

#### Acceptance Criteria (AC):
- [ ] AC1: Visual hierarchy highlights [Primary Element] above the fold.
- [ ] AC2: Color contrast meets WCAG AA standards (>= 4.5:1 ratio).
- [ ] AC3: Output provided in [Formats, e.g. SVG, PNG @2x, WebP].
- [ ] AC4: Responsive across 375px, 768px, and 1280px breakpoints.
```
