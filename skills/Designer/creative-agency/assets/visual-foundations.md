# Bộ nền tảng thị giác của dự án

Hồ sơ làm việc và nội dung cho phần đầu deck. Phải đi kèm board/asset bằng hình; file chữ này không thay thiết kế. Thu gọn theo brief, giữ phần đã chốt. Không bắt người dùng điền.

## Từ nghiên cứu tới hướng chọn

- Dự án, phiên bản, mục tiêu thị giác và ràng buộc nhận diện:
- Phát hiện có nguồn làm thay đổi hướng thiết kế:
- Ý tưởng và thao tác tạo hình, diễn đạt ngắn:
- Các hướng/thử nghiệm thực đã làm; file nào, vì sao chọn hoặc loại:
- Moodboard: file/trang, nguồn, điều học và cách biến đổi; tách rõ ảnh tham khảo với tác phẩm gốc:

## Bảng nền tảng bằng hình và kho tài sản

| Thành phần | Giữ sẵn / phát triển mới / không cần, vì sao | Quyết định liên hệ ý tưởng | Asset/board thực và phiên bản | Vai trò, phạm vi biến đổi và phép thử |
|---|---|---|---|---|
| Logo / title treatment / lockup | | | | |
| Typography và hierarchy | | | | |
| Màu sắc theo vai trò | | | | |
| Motif / texture / pattern | | | | |
| Ngôn ngữ hình, ảnh, vật liệu | | | | |
| Bố cục biểu cảm và thông tin | | | | |
| Chiều sâu / không gian / chuyển động khi có trong scope | | | | |

Chỉ điền file đã tồn tại; ảnh mẫu cần được mở xem. Ghi phần tái sử dụng được và phần còn phẳng hóa. Với thành phần không cần mới, chỉ rõ cách dùng cái sẵn có hoặc lý do bỏ, không tạo cho đủ bảng.

## Thử hệ trước khi mở rộng

- Tình huống khó/khác nhiệm vụ đã thử và vì sao chọn:
- File proof, nội dung thật, quan sát và điều chưa đứng vững:
- Sửa nền tảng nào; ứng dụng nào cần cập nhật:
- Trạng thái: đang khám phá / cần sửa / đủ dùng nội bộ để phát triển / người dùng đã chọn bản cụ thể:
- Phần còn phải triển khai trong phạm vi dự án:

## Lịch sử phát triển thực

| Phiên bản | Phát hiện từ nghiên cứu/thử nghiệm | Thành phần thay đổi | Asset và ứng dụng bị ảnh hưởng |
|---|---|---|---|

Đưa vào deck các mẫu và quyết định giúp hiểu sự phát triển; không bịa sketch, không dùng bảng quy trình che việc thiếu sản phẩm.
