### Core Architecture Rules:
1. **INTERNAL LANGUAGE STANDARDIZATION:**
   - **Internal Reasoning & Skill Execution:** All internal system instructions, tool execution, reasoning loops, and file schemas are processed in **English** for maximum LLM determinism and zero hallucination.
   - **User Communication:** The Agent communicates naturally in the user's language (Vietnamese or English) while preserving exact design/technical terms.
2. **ZERO-WASTE PROGRESSIVE DISCLOSURE:**
   - **Layer 1 (Router):** Ingest only this `.agent/AGENTS.md` / `.agent/CODEX.md` dispatch table.
   - **Layer 2 (Skill Core):** Load only the specific target `SKILL.md` in `.agent/skills/<Role>/<SkillName>/SKILL.md`.
   - **Layer 3 (References & Assets):** Open `.agent/references/` or specific `assets/` only when deep execution requires it.
3. **MANDATORY CONTINUOUS BANGIAO UPDATES:**
   - Every single prompt invocation that introduces or modifies code, designs, or architecture **MUST** immediately and continuously update all 4 files in `.agent/.bangiao/`:
     - [`.agent/.bangiao/ke-hoach.md`](file:///c:/Users/nguye/Downloads/Agency_Designer_skill/.agent/.bangiao/ke-hoach.md)
     - [`.agent/.bangiao/thay-doi.md`](file:///c:/Users/nguye/Downloads/Agency_Designer_skill/.agent/.bangiao/thay-doi.md) (Rolling 3-prompt window)
     - [`.agent/.bangiao/danh-gia.md`](file:///c:/Users/nguye/Downloads/Agency_Designer_skill/.agent/.bangiao/danh-gia.md)
     - [`.agent/.bangiao/ket-qua-test.md`](file:///c:/Users/nguye/Downloads/Agency_Designer_skill/.agent/.bangiao/ket-qua-test.md)
4. **VISUAL DNA SINGLE SOURCE OF TRUTH (`visual-dna.json`):**
   - Inspired by ComfyUI / Stable Diffusion IP-Adapter & Seed Locking.
   - Every Design / Campaign project MUST initialize [`.agent/.bangiao/visual-dna.json`](file:///c:/Users/nguye/Downloads/Agency_Designer_skill/.agent/.bangiao/visual-dna.json) storing: Exact color tokens (Hex, RGB, CMYK, Pantone, Rich Black), Typography Scale, Mascot specs, and SVG `<defs>` with `<symbol>` of Key Motifs and seamless patterns.
   - When executing individual assets (Tickets, Lightstick, Social post, Website), the Agent MUST strictly reference and inherit from `visual-dna.json` to guarantee 100% visual consistency.
5. **ANTI-OVERVIEW & MULTI-PACK CAMPAIGN PIPELINE:**
   - Inspired by AutoGPT / LangChain Plan-and-Execute architecture.
   - FORBIDDEN to collapse an entire campaign into a single superficial overview file.
   - Decompose campaign briefs into 5 Standard Production Packs (Pack 01: Brand Identity & Motif, Pack 02: Digital & Social Lifecycle, Pack 03: Event Merchandise & Tickets, Pack 04: Experiential Stage LED & POSM, Pack 05: Creative Experiential Web). Execute pack-by-pack with 100% depth.
6. **LAZY/BATCH BANGIAO FOR CREATIVE PRODUCTION:**
   - During active design/code iteration of individual assets, the Agent updates `visual-dna.json` immediately and dedicates 100% of output tokens to production assets (SVG, ExtendScript, CSS/JS). Comprehensive 4-file `.bangiao/` syncing occurs at milestone sign-offs.
7. **ANTI-SAAS EXPERIENTIAL WEB RULE:**
   - For Event, Music Festival, and Brand Launch websites, standard SaaS/B2B dashboard layouts (shadcn-ui tables/cards) are STRICTLY FORBIDDEN. Enforce 100vh Hero with kinetic typography, GSAP scrollytelling, interactive 3D physical ticket tier selector, and animated background motifs.

## 4. CONTINUOUS BANGIAO UPDATE PROTOCOL

Whenever the client issues a prompt that creates or alters state, the Agent MUST execute the following pipeline in `.agent/.bangiao/`:

1. **`visual-dna.json` (Visual Single Source of Truth):** Keeps colors, fonts, mascot specs, and SVG `<defs>` locked.
2. **`ke-hoach.md` (Kế hoạch):** Synthesizes BA requirements, Engineering architectural decisions (ADRs), and Designer token specifications.
3. **`thay-doi.md` (Thay đổi & CodeGraph):** Updates the Rolling 3-Prompt Window (Prompt N, N-1, N-2) recording AST symbols modified via CodeGraph.
4. **`danh-gia.md` (Đánh giá):** Evaluates performance, token consumption, diacritic safety, and QC/QA quality gates.
5. **`ket-qua-test.md` (Kết quả):** Compares deliverables against the Acceptance Criteria in `ke-hoach.md` using BA validation, confirming 100% pass across Codex models.
